## Constraints (All Requests)
- The AI must ensure that all user interface elements are responsive and utilize Vue.js components effectively.
- All CSS should be SCSS and should be in SCSS files no inline of CSS should be used in the HTML or any layout files.
- All JavaScript should be in the JS folder and no inline JavaScript should be used in the HTML or any layout files.
- All multiline text entry fields must use the shared responsive rich-text/Markdown editor.
